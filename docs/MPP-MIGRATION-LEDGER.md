# Opsis Media Player Pro → Opsis Media Suite: κατάλογος μεταφοράς (ledger)

Σκοπός: να μη χαθεί τίποτα πριν αρχειοθετηθεί το repo `OpsisMediaPlayerPro` (παγωμένο στο v1.6.1). Το repo ΔΕΝ έχει αλλάξει από αυτή τη δουλειά· όλα διαβάστηκαν μόνο για ανάγνωση.

**Πηγές που διαβάστηκαν:** τα αρχεία του repo (README, CHANGELOG, docs/RELEASE-1.2.0…1.6.1, docs/CONVERTER.md, όλα τα μενού και οι εντολές του κώδικα), τα GitHub releases (1.2.0–1.6.1 — δεν υπάρχουν issues), `C:\w\TASKS-MASTER.md` §4 και §18–19, `C:\w\TASKS-mediaplayer.md`, `C:\w\OPSIS_UNIFIED_MASTER_PLAN.md` Ενότητα 4, `AUDIT-COORDINATOR.md` και `ROADMAP-STUDY.md` (σημεία Media Player Pro), και τα αιτήματα του χρήστη μέσα στην τοπική συνομιλία του MPP (94 μηνύματα, 22/10–10/11/2026).

**Κατάσταση:** `ΕΓΙΝΕ` = υπάρχει στο Media Suite (2.3.0/2.3.1) · `ΡΟΥΜΑΠ` = καταγράφηκε στο WAVEFRAME_ROADMAP.md (§ «Από το Media Player Pro») · `ΑΠΟΡΡΙΦΘΗΚΕ` = δεν θα γίνει, με λόγο · `Ν/Α` = δεν ισχύει στο Suite.

## 2. Ανοιχτά θέματα του ίδιου του MPP και τι απέγιναν

## 3. Τι ΔΕΝ μεταφέρθηκε (ρητά)
1. Κωδικοί/κλειδιά υπηρεσιών υποτίτλων (σκόπιμα).
2. DVD, Blu-ray, κάμερα/λήψη συσκευής.
3. Αυτόματος τερματισμός υπολογιστή μετά την αναπαραγωγή.
4. Εφέ βίντεο gamma/deinterlace/sharpen στην αναπαραγωγή.
5. Η δεύτερη εμφάνιση «Wave»/«Classic» ως ξεχωριστή έννοια, το πλευρικό πάνελ με hover, η θέση παραθύρου του MPP.
6. Λήψη υποτίτλων από ιστοτόπους (και ο συγχρονισμός τους), πληροφορίες ταινίας από το διαδίκτυο, Chromecast/DLNA, κανάλια/καθυστέρηση ήχου, κανονικοποίηση/συμπιεστής στο βίντεο, κεφάλαια, κοπή A-B χωρίς απώλεια, ακολουθία καρέ/contact sheet, εξαγωγή .m3u — όλα στο ΡΟΥΜΑΠ.

## 4. Αρχειοθέτηση περιεχομένου
Το README, το CHANGELOG, τα release notes 1.2.0–1.6.1, το CONVERTER.md, τα 16 screenshots/social-preview και το εικονίδιο του MPP αντιγράφηκαν (μόνο ανάγνωση της πηγής) στο `docs/mpp-archive/`. Το πρόγραμμα (C#/WPF) δεν μεταφέρεται — ο κώδικας μένει στο παγωμένο repo.
